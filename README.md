# Takimi

Swipe djathtas për ❤️, majtas për ✕ — bëj match dhe bisedo. Profile fiktive, demo.

## Veçori

- 8 profile fiktive shqiptare (emër, moshë, qytet, bio, interesa)
- Swipe me butona ✕ / ❤️ dhe me shigjetat ← → të tastierës, me animacion
- Disa profile "kthejnë like" → modal celebrimi "🎉 Është Match!"
- Tab "💘 Matches" me listën e match-eve
- Bisedë për çdo match: dërgo mesazhe, merr përgjigje automatike shqip pas 1s
- Mesazh "S'ka më profile" + buton Reseto kur mbarojnë profilet
- Match-et, progresi dhe bisedat ruhen në localStorage
- Etiketim i qartë: profile fiktive — demo, jo njerëz të vërtetë
